# base-editor-tool
#**AB1 to Excel** is a browser-based tool for analyzing Sanger sequencing chromatograms in base editing experiments. It reads AB1 files, extracts local peak heights from the four fluorescence channels, and reports two complementary metrics: **pair-normalized signal**, calculated as the edited-base signal divided by the sum of the original- and edited-base signals, and **total-signal fraction**, calculated as the edited-base signal divided by the sum of all four base signals. The tool supports batch analysis, guide sequence matching, forward and reverse-complement orientations, optional triplicate summaries, interactive chromatogram visualization, and export to Excel or CSV. All sequencing data are processed locally in the browser without uploading files to a server. These signal-based measurements provide estimates of base editing outcomes and should be interpreted in the context of sequencing quality and experimental controls.
